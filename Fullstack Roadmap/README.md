# Fullstack Roadmap
Roadmap personalizado para desarrollo web


```text
Apache/Nginx  → sirve/proxifica HTTP
Reverse proxy → puerta de entrada a tus aplicaciones
Docker        → empaqueta aplicaciones
Compose       → coordina containers
Redis         → datos rápidos/cache/sesiones/colas
MySQL         → almacenamiento persistente
Microservicios→ arquitectura basada en varios servicios
Kubernetes    → administra containers a gran escala
CI/CD         → automatiza el despliegue
tmux          → administra cómodamente terminales
```
